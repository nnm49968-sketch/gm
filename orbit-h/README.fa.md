# مدار: گره هشت (نسخهٔ سخت) | راهنمای نصب و اجرای مسابقه

یک سرور برای کل سالن اجرا کنید؛ دانشجوها فقط مرورگر گوشی لازم دارند. نصب برنامه روی گوشی، کاغذ، چاپ یا اینترنت عمومی در زمان بازی لازم نیست؛ اما همه باید به همان سرور دسترسی داشته باشند. باز کردن index.html به‌تنهایی بازی چندنفره را راه نمی‌اندازد.

## ۱. تست روی کامپیوتر

فایل ZIP را استخراج کنید، ترمینال را در پوشه‌ای که `start.py` قرار دارد باز کنید. Python 3.11 یا 3.12 و اینترنت برای نصب اولیهٔ بسته‌ها لازم است.

**لینوکس و macOS:**
```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python start.py
```
در Ubuntu اگر ساخت محیط مجازی خطا داد، بستهٔ `python3-venv` را نصب کنید. اگر از `uv` استفاده می‌کنید: `uv venv --python 3.12` سپس `uv pip install -r requirements.txt` و بعد همان دستور اجرای بالا.

**ویندوز (PowerShell، بدون نیاز به Activate):**
```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe start.py
```

- بازیکن: `http://127.0.0.1:8081/`
- برگزارکننده: `http://127.0.0.1:8081/admin` — نشانی را مستقیم تایپ کنید. صفحهٔ بازی لینک ورود مدیر ندارد. بعد از ورود، در فهرست تیم‌ها پاسخ‌نامهٔ تیم موردنظر را باز کنید؛ کلید هر چهار مرحله برای همان تیم است. هنگام نمایش بازی روی ویدئوپروژکتور، تب مدیریت را روی پرده نیندازید.
- فونت ایران‌یکان پروژه از فایل‌های محلی در `static/fonts/` بارگذاری می‌شود؛ هیچ درخواست فونتی به سرویس بیرونی نمی‌رود. برای انتشار عمومی، مجوز استفادهٔ وب فونت خودتان را بررسی کنید.
- اولین اجرا رمز تصادفی مدیر را در `data/admin.password` می‌سازد. فایل را فقط روی سیستم میزبان با ویرایشگر متن باز کنید. رمز پیش‌فرض مشترک وجود ندارد. برای پایان اجرا در ترمینال Ctrl+C بزنید. اگر پورت اشغال بود `--port 8082` را به دستور اجرا اضافه کنید.
- در پنل وارد شوید، زمان و ظرفیت را ذخیره کنید و «باز کردن تیم‌یابی» را بزنید. در صفحهٔ بازیکن با نام مستعار تیم بسازید. برای عضو دوم **مرورگر دیگر** یا پروفایل خصوصی جدا باز کنید و کد همان تیم را بزنید. دو تب عادی یک مرورگر، دو بازیکن نیستند.
- منتظر اتمام تیم‌یابی بمانید یا «شروع فوری مأموریت» را بزنید. سرنخ هر دو نفر را باز کنید؛ یک نفر پیام بفرستد و نفر دیگر پاسخ تیم را ثبت کند. قبل از مراسم نتایج تست را از پنل بازنشانی کنید.

## ۲. تست با گوشی‌های واقعی روی وای‌فای سالن

به‌جای دستور اجرای قبلی، روی میزبان بزنید:
```sh
.venv/bin/python start.py --lan
```
در ویندوز: `.\.venv\Scripts\python.exe start.py --lan`. گوشی‌ها به همان شبکه وصل شوند. با `hostname -I` در لینوکس، `ipconfig` در ویندوز یا تنظیمات Wi-Fi در مک، IP شبکهٔ میزبان را پیدا کنید. مثلاً اگر IP برابر `192.168.1.23` بود، نشانی بازی روی گوشی **`http://192.168.1.23:8081/`** است؛ روی گوشی localhost نزنید. دسترسی ورودی TCP 8081 را فقط در شبکهٔ خصوصی مجاز کنید. اگر لپ‌تاپ می‌بیند ولی گوشی نه، جداسازی کاربران وای‌فای (AP/client isolation)، فایروال، VPN و شبکهٔ مهمان را بررسی کنید. برای شبکهٔ عمومی از HTTPS بخش بعد استفاده کنید. دستگاه میزبان نباید به خواب برود.

## ۳. نصب روی سرور اینترنتی با Docker و HTTPS

مسیر زیر برای **یک سرور لینوکسی با Docker Engine و افزونهٔ Docker Compose و Caddy روی خود میزبان** است. یک دامنه مثل `play.example.org` را با رکورد A به IP عمومی سرور وصل کنید (AAAA فقط اگر IPv6 واقعاً کار می‌کند). پورت‌های TCP 80 و 443 برای Caddy باز باشند؛ 8081 نباید عمومی باشد. اگر وب‌سرور دیگری روی 80/443 دارید، از همان reverse proxy با TLS و حفظ Host استفاده کنید، نه دو وب‌سرور روی یک پورت.

۱. پوشهٔ پروژه را روی سرور کپی و در همان پوشه یک بار رمز و کلید تصادفی بسازید. این دستور **فایل موجود را بازنویسی نمی‌کند**:
```sh
umask 077
python3 -c "import secrets; f=open('.env','x'); print('ORBIT_ADMIN_PASSWORD='+secrets.token_urlsafe(24),'ORBIT_SECRET='+secrets.token_urlsafe(48),sep='\n',file=f); f.close()"
docker compose up -d --build
docker compose ps
curl -fsS http://127.0.0.1:8081/api/state
```
رمز ورود پنل مقدار `ORBIT_ADMIN_PASSWORD` در `.env` است. `.env` را ارسال عمومی یا داخل git ذخیره نکنید. کلید `ORBIT_SECRET` باید بین اجراها ثابت بماند. اگر اسم پوشهٔ Compose را عوض کنید، volume پیش‌فرض هم ممکن است عوض شود.

۲. نمونهٔ `Caddyfile.example` را باز کنید، `play.example.org` را به دامنهٔ واقعی تغییر دهید و بلوک آن را به `/etc/caddy/Caddyfile` اضافه کنید (تنظیم سایت‌های قبلی را پاک نکنید). سپس:
```sh
sudo caddy validate --config /etc/caddy/Caddyfile
sudo systemctl reload caddy
```
اگر سرویس هنوز فعال نیست، بعد از اعتبارسنجی `sudo systemctl enable --now caddy` بزنید. اکنون `https://دامنه/` و `https://دامنه/admin` را در مرورگر باز کنید. کانتینر برای TLS پشت پراکسی تنظیم شده است: تست سلامت با HTTP روی loopback مجاز است ولی **ورود و بازی روی سرور را از نشانی HTTPS دامنه انجام دهید**. برای اجرای HTTP محلی از بخش ۱ استفاده کنید.

۳. دستورات نگهداری:
```sh
docker compose logs --tail 80 orbit
docker compose restart orbit
```
داده در SQLite و volume نام‌دار `game` است. `docker compose down -v` آن را حذف می‌کند؛ برای به‌روزرسانی از `docker compose up -d --build` در همان پوشه استفاده کنید. خروجی CSV فقط رتبه‌بندی است، نه بکاپ. برای نسخهٔ پشتیبان سازگار از دیتابیس فعال:
```sh
umask 077
docker compose exec -T orbit python -c "import sqlite3; s=sqlite3.connect('/srv/orbit/data/orbit.sqlite3'); d=sqlite3.connect('/tmp/orbit-backup.sqlite3'); s.backup(d); d.close(); s.close()"
docker compose cp orbit:/tmp/orbit-backup.sqlite3 ./orbit-backup.sqlite3
```
فایل بکاپ و `.env` را امن و جدا از سرور نگه دارید. این طراحی برای یک نمونهٔ برنامه و دیسک محلی است، نه چند سرور با SQLite مشترک. پیش از مراسم پرتعداد، با شبکه و تعداد گوشی مورد انتظار خودتان تمرین کنید.

## ۴. چک‌لیست روز اجرا

- تنظیم پیشنهادی: تیم شش تا هشت نفره، ۱۰ دقیقه تیم‌یابی. زمان بازی را متناسب با برنامه و پس از یک دور آزمایشی تعیین کنید. همه بر یک ساعت سرور بازی می‌کنند؛ زمان با رفرش گوشی از نو شروع نمی‌شود.
- نام مستعار کافی است؛ نام تیم عمومی است. همهٔ اعضا اختیار ارسال پاسخ، گرفتن راهنما و گفت‌وگو دارند. جای بازیکن با کوکی همین مرورگر حفظ می‌شود؛ وسط بازی مرورگر را عوض یا کوکی را پاک نکنید. کد تیم جایگزین بازیابی هویت نیست.
- حل هر مرحله ۱۰۰ امتیاز دارد؛ اگر تیم راهنمای آن مرحله را باز کند، حل آن ۸۰ امتیاز دارد. رتبه ابتدا با امتیاز، سپس تعداد مراحل حل‌شده، زمان آخرین پیشروی و در نهایت شناسهٔ تیم تعیین می‌شود.
- از پنل: شمار تیم و نفرات، جست‌وجو و فهرست اعضا، زمان و مرحله، توقف و ادامه، پایان زودهنگام، اعلان، حذف عضو، اصلاح امتیاز، وقایع و خروجی CSV در دسترس است. **حذف آخرین عضو می‌تواند خود تیم را حذف کند.** پیش از بازنشانی خروجی بگیرید. در طول مسابقه سیستم و شبکه را روشن نگه دارید؛ توقف زمان را از پنل بزنید، نه با خاموش کردن سرور.
- برای سناریوی اجرا و روش هدایت معماها فایل `HOST.md` کنار همین راهنما را بخوانید. برای اجرای تست‌های خودکار از ریشهٔ پروژه:
```sh
.venv/bin/python -m unittest discover -s tests -v
```
